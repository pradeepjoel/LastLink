# Roadmap

1. **Milestone 1 complete:** Terminal 2 → Jean Médecin scheduled tram slice, simulated delay, API, web UI, tests.
2. **Milestone 2 complete:** official Lignes d’Azur and ZOU Express scheduled feeds; Nice centre, Antibes, Cannes; bounded multimodal complete-itinerary search; validated tram-to-rail walk; configurable feasibility assumptions, last connection, passenger timeline, synthetic and optional official-feed tests.
3. **Milestone 3, pending source access:** validate live transport and flight feeds, rights and refresh cadence; only then add live monitoring or alerts.
4. **Milestone 4:** optional grounded explanation provider with deterministic routing as the source of truth.
5. **Milestone 5:** evaluate zero-cost hosting, operational monitoring, accessibility, and user testing before public launch.
